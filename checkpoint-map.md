## Process Findings

The sprint produced visible contributions from all five members. The team experienced direct-to-main commits, inconsistent commit-message formatting, delayed reviews and confusion between local and deployed behaviour. These events were retained in the Git history rather than rewritten.

The team responded by clarifying the branch and commit convention, using task-linked pull requests for later work, requesting teammate reviews, fixing deployment defects and packaging the Git and Board exports.

## Remaining or Accepted Limitations

- The MVP uses fictional hard-coded information.
- The application is suitable only for a controlled demonstration.
- It is not connected to live Northstar services.
- Production authentication, security, privacy, monitoring and scale testing remain incomplete.
