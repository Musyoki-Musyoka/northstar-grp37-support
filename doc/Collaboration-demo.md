## 4. Demo Rehearsal

**Demo Objective:**  
Demonstrate that the Northstar Support Dashboard can handle the selected support scenarios through self-service.

**Demo Overview:**

| Demo Item | Details |
| :--- | :--- |
| **Demo Owner** | Anthony Musyoka |
| **Supporting Members** | Amos, Anne, Vincent, Marylene |
| **Project Board** | View 1 · Northstar Sprint Board |

### Demo Steps
1. Open the dashboard.
2. Demonstrate the homepage.
3. Demonstrate Order Status:
   * Enter a valid fictional order number.
   * Show the resulting order status.
4. Demonstrate Returns & Refunds:
   * Follow the return/refund decision path.

> ⚠️ **Demo Limitations:**
> * The prototype uses fictional order data.
> * Not connected to Northstar’s live order or return systems.
> * Security, accessibility, and production-scale testing are needed before deployment.
