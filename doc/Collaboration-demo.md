4. Demo Rehearsal
Demo objective: Demonstrate that the Northstar Support Dashboard can handle the selected support scenarios through self-service.
Demo steps:
•	Open the dashboard.
•	Demonstrate the homepage.
•	Demonstrate Order Status.
•	Enter a valid fictional order number.
•	Show the resulting order status.
•	Demonstrate Returns & Refunds.
•	Follow the return/refund decision path.

Demo limitations:
-	The prototype uses fictional order data
-	Not connected to North star’s live order or return systems.
-	Security, accessibility and production-scale  testing needed before deployment
